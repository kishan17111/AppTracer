# 📱 App Tracer

<div align="center">

### Track Every Install. Monitor Every Removal.

An Android application monitoring tool that tracks applications installed and uninstalled within the last **30 days**, along with their date and time.

## ✨ Features

| Feature | Description |
|:---|:---|
| 📥 Installed Apps | View currently installed applications. |
| 🗑️ Deleted Apps | Identify recently uninstalled applications. |
| 🕒 Date & Time | View installation and deletion timestamps. |
| 📅 30-Day History | Track application changes over the last 30 days. |
| 🔍 App Monitoring | Monitor all types of applications, not just root-related apps. |

## ⚙️ How It Works

```text
      Android Device
            │
            ▼
    Application Monitoring
            │
       ┌────┴────┐
       ▼         ▼
   Installed   Deleted
      Apps       Apps
       │         │
       └────┬────┘
            ▼
     Date & Time Records
            │
            ▼
      30-Day History
```

## 🎯 Purpose

- Monitor application installation and deletion activities.
- Identify recently removed applications.
- Review application changes with timestamps.
- Maintain a history of device application activity.

## 🚀 Future Enhancements

## ⚠️ Note

Tracking accuracy depends on Android version, permissions, and system restrictions. Historical records generally require application information or events to have been collected beforehand.
